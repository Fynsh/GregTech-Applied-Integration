二、层叠顺序（模型里 element 从下到上；空层不生成 element）
  F2PL 框架      框架 / 框架-超净 → 类型渲染层{T} → 等级渲染层{L}
  F2PL 玻璃      玻璃 / 玻璃-超净 → 等级渲染层{L}
  PEC5 供应器    核心渲染背景 → 类型{T} → [扩展渲染层] → 应用集成样板供应器
  PEC5 处理核心  核心渲染背景 → 类型{PT对应外壳} → [扩展渲染层] → 电压等级{V} → 覆盖版{PT}
  PEC5 速度核心  核心渲染背景 → 类型{T} → [扩展渲染层] → 电压等级{V} → 覆盖版/速度
  PEC5 监控器    核心渲染背景 → 类型{T} → [扩展渲染层] → 应用集成监控器
  PEC5 变压器    核心渲染背景 → 电压等级{V} → 覆盖版/变压器
  其它           单层贴图；超净间为 top/side/bottom 三面

  玻璃族（玻璃 / 超净玻璃）的底图带透明孔洞，注册时额外 noOcclusion()：
  否则相邻方块的贴合面会被剔除，透过孔洞会看到空洞。
  其余方块（底图不透明）正常遮挡相邻面。
